# 07-Intelligence

Institutionelles Gedächtnis — Entscheidungen, Meetings, Recherche.

**Unterordner:**
- `decisions/` — Wichtige Entscheidungen mit Kontext und Begründung (`YYYY-MM-DD-{thema}.md`)
- `meetings/` — Meeting-Notizen, manuell angelegt oder per `/capture` erfaßt (`YYYY-MM-DD-{thema}.md`)

**Tipp:** Entscheidungen dokumentieren spart später Stunden. Format: Was entschieden, warum, welche Alternativen verworfen.
