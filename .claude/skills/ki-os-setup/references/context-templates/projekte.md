Jedes Projekt bekommt einen eigenen Unterordner: `04-projects/{projektname}/`, mit einer
Notiz, die wie das Projekt heißt (`{projektname}.md`, nicht `README.md` — sonst wäre
`[[README]]` bei mehreren Projekten mehrdeutig).

## Struktur pro Projekt

```
04-projects/{name}/
  {name}.md               — Ziel, Status, nächste Schritte
  plan-YYYY-MM-DD.md      — Implementierungspläne
  [weitere Dateien]       — Notizen, Recherche, Drafts
```
